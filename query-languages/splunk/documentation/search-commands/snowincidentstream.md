# snowincidentstream

The `snowincidentstream` command is used with the Splunk Add-on for ServiceNow.

For information about this command, see [Use custom streaming search commands for the Splunk Add-on for ServiceNow](http://docs.splunk.com/Documentation/AddOns/released/ServiceNow/Usestreamingcommands) in *Splunk Add-on for ServiceNow*.
